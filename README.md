# MontDang

Tienda online de maquillaje en tonos café y beige, hecha con React y Vite.

## Autora
Danna González - Diseño Web

## Tecnologías
- React
- Vite
- Tailwind CSS

## Componentes
- Navbar
- Hero
- Carrusel
- Card
- Productos
- Footer

## Cómo correrlo
1. Clonar el repositorio
2. Instalar dependencias:
```
   npm install
```
3. Iniciar el proyecto:
```
   npm run dev
```
